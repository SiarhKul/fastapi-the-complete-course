# FastAPI: The Complete Course

Это репозиторий для учебного проекта "FastAPI: The Complete Course".

## 🚀 Начало работы

Этот проект использует **Poetry** для управления зависимостями и виртуальным окружением.

### Предварительные требования

Перед началом работы убедитесь, что у вас установлены:

* **Python** (версия 3.11 или выше)
* **Poetry** ([инструкция по установке](https://python-poetry.org/docs/#installation))

### Установка

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd fastapi-the-complete-course
    ```

2.  **Установите зависимости:**
    Выполните команду `poetry install`. Она автоматически создаст виртуальное окружение в папке проекта и установит все необходимые пакеты из файла `pyproject.toml`.
    ```bash
    poetry install
    ```

## 🏃 Запуск приложения

1.  **Активируйте виртуальное окружение:**
    Чтобы все команды выполнялись в правильном окружении, активируйте его:
    ```bash
    poetry shell
    ```

2.  **Запустите сервер для разработки:**
    Используйте `uvicorn` для запуска вашего FastAPI приложения.
    ```bash
    uvicorn main:app --reload
    ```
    * `main`: это файл `main.py`.
    * `app`: это объект `app = FastAPI()`, созданный в `main.py`.
    * `--reload`: флаг, который автоматически перезапускает сервер при изменении кода.

3.  **Откройте документацию API:**
    После запуска сервера перейдите в браузере по одному из следующих адресов:
    * **Swagger UI**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
    * **ReDoc**: [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## ✅ Тестирование и форматирование

* **Запуск тестов:**
    Для запуска тестов используйте `pytest`:
    ```bash
    pytest
    ```

* **Форматирование кода:**
    Проект использует `black` для автоматического форматирования кода. Чтобы отформатировать все файлы, выполните:
    ```bash
    black .
    ```
